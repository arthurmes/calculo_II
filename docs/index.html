Visualizações 3D para Cálculo II

Uma pequena coleção de superfícies interativas para discutir gráficos, planos tangentes, pontos críticos, regiões e sólidos. Arraste com o mouse ou com o dedo para girar.

No celular: use um dedo para girar, dois dedos para aproximar/afastar. Se ficar pesado, recarregue a página e evite muitas abas abertas.
